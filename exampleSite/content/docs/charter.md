## Purpose

This charter defines the structural intent, decision scope, and responsibilities for the governance surface.

{{< callout type="info" title="Notice" >}}
This document is a reference surface, not an enforcement mechanism.
{{< /callout >}}

## Scope

The governance scope is limited to:

- Structural decisions
- Documented decision records
- Policy publication

## Boundaries

{{< callout type="warning" title="Warning" >}}
This charter does not define operational execution or staffing.
{{< /callout >}}

## Decision Flow

1. Proposal submitted
2. Review window established
3. Decision recorded

### Decision Record Table

| Stage | Owner | Output |
| --- | --- | --- |
| Proposal | Author | Draft doc |
| Review | Maintainers | Notes |
| Decision | Steering | Record |
